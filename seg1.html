一、问题：你不是缺更好的提示词，是缺一个会自己转的系统

过去两年，整个行业都在卷提示词：system prompt 越写越长，few-shot 越堆越多，思维链越绕越花。结果呢？Agent 还是走两步就停、做一半就忘，你还得一句一句哄着它往下走。

2026 年 6 月，Google 工程师 Addy Osmani 发表了一篇题为《Loop Engineering》的文章，一周之内"循环工程"成了整个 AI 圈都在用的词。OpenAI 的工程师 Peter Steinberger 直接喊话：别再给 coding agent 写提示词了，去设计能自己提示 agent 的循环。Claude Code 的负责人 Boris Cherny 更干脆：他现在的工作就是写循环。

转变只有一句话：工作的基本单位不再是"提示词"，而是"循环"。你把循环设计好一次，Agent 在里面自己找活、自己干、自己验、自己记状态。你从司机，变成了设计师。
